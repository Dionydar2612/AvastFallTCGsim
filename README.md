# AvastFall Playtest (เว็บทดลองเล่น)

เว็บสแตติก ไม่ต้อง build ไม่ต้องใช้ Node เปิด `index.html` ผ่านโฮสต์ใดก็ได้ (เปิดไฟล์ตรง ๆ ก็เล่นได้ แต่เรียก card-api ไม่ได้ ต้องผ่านโฮสต์)

## โครงสร้างไฟล์ (แยกตามหน้าที่)

```
index.html                 โครงหน้า + ลำดับโหลดสคริปต์
css/style.css              สไตล์ทั้งหมด
assets/card-back.jpg       ลายหลังการ์ด (รูปหน้าการ์ดดึงจาก card-api ทั้งหมด)

js/engine/engine.js        กติกาเกม (ไม่แตะ DOM) · กติกาคงที่: Domain 3 ใบ, เด็ค 60 ใบ, ธีอัลฟีตามข้อความ
js/effects/_kit.js         ตัวช่วยที่สคริปต์การ์ดใช้ร่วมกัน
js/effects/sd01..sd04.js   เอฟเฟกต์การ์ดแยกตามชุด  FX['SD04-012'] = {...}  + NOTES['SD04-012'] = '...'
js/bot.js                  บอท

js/data/cards-api.js       ชั้นดึงข้อมูล: card-api, สำเนาในเบราว์เซอร์, URL รูปการ์ด, ตรวจการ์ดใหม่/ข้อความเปลี่ยน
js/data/snapshot.js        ชุดการ์ดสำรอง และเป็น "ข้อความที่สคริปต์เขียนไว้ตามนั้น"

js/ui/*.js                 หน้าจอ (base, notes, data-sync, decks, render, setup, mydecks, game, modals, events, main)
```

UI ไม่รู้เรื่องการดึงข้อมูล (อ่านผ่าน `AF.cardData` เท่านั้น) และสคริปต์เอฟเฟกต์ไม่รู้เรื่อง UI แก้ส่วนหนึ่งไม่ต้องแตะอีกส่วน

## แก้/เพิ่มเอฟเฟกต์การ์ด
1. เปิดหน้าเว็บ → ชิป "ข้อมูลการ์ด" ด้านบน จะแสดงรายการ "ยังไม่มีสคริปต์" และ "ข้อความต่างจากที่สคริปต์เขียนไว้" (กด "ดูส่วนที่ต่าง" จะเห็นข้อความเดิมเทียบข้อความใน card-api)
2. แก้ `FX[รหัสการ์ด]` ในไฟล์ชุดนั้นใน `js/effects/` และถ้าตีความข้อความไม่ตรงตัวให้เขียน `NOTES[รหัสการ์ด]` ไว้ข้างกัน (แสดงในปุ่ม "ข้อสังเกต")
3. แก้รายการการ์ดนั้นใน `js/data/snapshot.js` ให้เหมือนข้อความล่าสุดใน card-api ป้าย "ข้อความเปลี่ยน" จะหาย

## เชื่อมกับ card-api
- ค่าเริ่มต้น https://avastfalltcglist.onrender.com (แก้ได้ที่ชิป "ข้อมูลการ์ด" หรือเปิดด้วย `?api=https://...`)
- ดึง `/api/cards` `/api/decks` `/api/elements` ทุกครั้งที่เปิดหน้า และเมื่อกลับมาที่แท็บหลังผ่านไปเกิน 90 วินาที เก็บสำเนาไว้ในเบราว์เซอร์ ถ้าต่อ API ไม่ได้จะใช้สำเนา หรือชุดสำรองใน `snapshot.js`
- **รูปการ์ดดึงจาก API** (`/images/<รหัส>.jpg?v=...` ตามฟิลด์ `image`) ไม่ได้ฝังในโค้ด ถ้ารูปโหลดไม่ได้จะเห็นลายหลังการ์ดแทน
- Render แพ็กเกจฟรีจะหลับเมื่อไม่มีคนใช้ การโหลดครั้งแรกอาจรอ ~30–60 วินาที

## หน้าตั้งค่า
เหลือเฉพาะ "โหมด" และ "ใครเล่นก่อน" ส่วนอื่นเป็นกติกาคงที่: Domain ต่อฝั่ง 3 ใบ · ธีอัลฟีตามข้อความการ์ด · เด็คต้อง 60 ใบเสมอ

## เด็คของฉัน
เก็บใน localStorage ของเบราว์เซอร์ (`af-mydecks`) ส่งต่อได้ด้วยปุ่ม "คัดลอกเป็นข้อความ" / "นำเข้าจากข้อความ"

## Deploy บน Render (Static Site)
1. push โฟลเดอร์นี้ขึ้น GitHub (หรือใช้ `render.yaml` ผ่าน Blueprint)
2. New → Static Site → Publish directory = `.` , Build command เว้นว่างหรือ `echo ok`
3. ตั้งชื่อ service เป็น `avastfalltcgsim`
