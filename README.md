# AvastFall Playtest (เว็บทดลองเล่น)

ไฟล์เดียว `index.html` (เอนจินกติกา + สคริปต์การ์ด + บอท + หน้าจอ รวมอยู่ในไฟล์นี้) ไม่ต้อง build ไม่ต้องใช้ Node

## Deploy บน Render (Static Site)
1. ใส่ไฟล์ในโฟลเดอร์ใหม่ push ขึ้น GitHub (หรือใช้ `render.yaml` นี้ผ่าน Blueprint)
2. New → Static Site → Publish directory = `.` , Build command เว้นว่างหรือ `echo ok`
3. ตั้งชื่อ service เป็น `avastfalltcgsim` จะได้ https://avastfalltcgsim.onrender.com/

## เชื่อมกับ card-api
- ค่าเริ่มต้นดึงการ์ดจาก https://avastfalltcglist.onrender.com (แก้ได้ในหน้าเว็บที่ชิป "ข้อมูลการ์ด" หรือเปิดด้วย `?api=https://...`)
- ดึง `/api/cards` `/api/decks` `/api/elements` ทุกครั้งที่เปิดหน้า และเมื่อกลับมาที่แท็บหลังผ่านไปเกิน 90 วินาที เก็บสำเนาไว้ในเบราว์เซอร์ ถ้าต่อ API ไม่ได้จะใช้สำเนา หรือชุดที่ฝังมากับหน้า (57 ใบ)
- Render แพ็กเกจฟรีจะหลับเมื่อไม่มีคนใช้ การโหลดครั้งแรกอาจรอ ~30–60 วินาที ระหว่างนั้นใช้ข้อมูลที่ฝังไว้ไปก่อน

## เด็คของฉัน
เก็บใน localStorage ของเบราว์เซอร์ (`af-mydecks`) ส่งต่อได้ด้วยปุ่ม "คัดลอกเป็นข้อความ" / "นำเข้าจากข้อความ"

## การ์ดใหม่ที่ยังไม่มีสคริปต์
Unit ใช้ค่า ATK/DEF/CRI จาก API ได้ทันที แต่เอฟเฟกต์ต้องมีสคริปต์ในโค้ดเอนจิน การ์ดที่ยังไม่มีสคริปต์เล่นได้โดยไม่มีเอฟเฟกต์ พร้อมป้าย ⚠ ในตัวแก้ไขเด็คและชิป "ข้อมูลการ์ด"
